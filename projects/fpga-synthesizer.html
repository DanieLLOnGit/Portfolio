Project

FPGA Digital Audio Synthesizer & Sequencer

A VHDL sequencer on a Basys 3 FPGA that automatically plays a full song through hardware note synthesis, no keyboard required. Built with a lab partner.

Overview

We were given a working “piano” VHDL module for the Basys 3 (Xilinx Artix-7): press a button, hear a note. The assignment was to turn it into an automatic player instead, one that performs a full song on its own with no human at the switches.

We picked “Mary Had a Little Lamb” for its recognizable, limited range of notes, then rebuilt the module around a hardware sequencer: a tempo generator ticks off a beat every quarter second, a step counter walks through the song, and a lookup table turns each step into the right note, looping indefinitely once it reaches the end.

Tech Stack

  • VHDL
  • Xilinx Artix-7
  • Basys 3
  • Vivado
  • Clock Dividers
  • FSM

Key Features

  • A tempo generator counts 250,000 pulses of a derived 1 MHz clock to produce one beat every 0.25 seconds, driving the timing for the entire song.
  • A 5-bit song-step counter advances on each beat through a lookup table of encoded notes, wrapping back to the first step once it reaches the end so the song repeats indefinitely.
  • Each encoded note is translated into its own clock-divider value that sets the output frequency, so the same synthesis hardware can play every note in the song.
  • An MMCME2-based clock manager takes the board’s 100 MHz input and derives the stable 1 MHz reference the whole design times off of.
  • Onboard LEDs mirror the reset state, the beat pulse, and the current step in binary, and the 7-segment display shows the active note, both used to debug the timing by eye instead of a logic analyzer.
