Nimbus

Built for an Amazon internal hackathon, where it reached the finals. Nimbus is a website that teaches you how to build AWS cloud infrastructure.

Overview

Most cloud training has you read documentation and watch walkthroughs. Nimbus flips that around - you learn AWS by building with it. You drag services onto a canvas, connect them, and watch a working architecture take shape, so the way services fit together becomes concrete instead of abstract.

It’s built for incoming interns meeting AWS for the first time. The interface keeps things approachable, turning ideas like message queues, event triggers, and managed databases into pieces you can place, wire up, and reason about visually. A built-in AI assistant, running on Amazon Bedrock, is there throughout to answer questions and help when you get stuck.

Built with

React and TypeScript on the front end. The Create workbench compiles your canvas into deployable AWS CDK, and the assistant is powered by Amazon Bedrock.

Key Features

  • Drag-and-drop builder for assembling AWS services into real cloud architectures.
  • Visual connections that make service-to-service relationships obvious at a glance.
  • Create - a free-form workbench that generates AWS CDK from your design when you hit Run.
  • Learn - step-by-step lessons that teach each service and build up to full working systems.
  • Challenge - open-ended problems you solve by designing the right infrastructure.
  • An Amazon Bedrock–powered AI assistant for in-context questions and help.
  • A beginner-first approach that makes complex cloud concepts easier to grasp.
