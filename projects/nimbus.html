Nimbus

Built alongside 3 hackers and finalist for an Amazon internal hackathon. Nimbus is a website that teaches you how to build AWS cloud infrastructure.

Overview

Most cloud training has you read documentation and watch walkthroughs. Nimbus flips that around - you learn AWS by building with it. You drag services onto a canvas, connect them, and watch a working architecture take shape, so the way services fit together becomes concrete instead of abstract.

It’s built for incoming interns meeting AWS for the first time. The interface keeps things approachable, turning ideas like message queues, event triggers, and managed databases into pieces you can place, wire up, and reason about visually. A built-in AI assistant, running on Amazon Bedrock, is there throughout to answer questions and help when you get stuck.

Tech Stack

  • React
  • TypeScript
  • Python
  • AWS Bedrock

Deployed publicly for the hackathon; since taken down.

Key Features

  • Drag-and-drop blocks representing AWS services and connect them with your cursor. The website will indicate if there is a service-to-service relationship between blocks.
  • There are three pages: Create, Learn, and Challenge. The Create page is a free-form workbench where you can build whatever infrastructure you feel. Click “Generate CDK” to automatically create the CDK for your design that can be imported into your own codebase. The Learn page has step-by-step lessons that teach you about each service. It also provides short lessons that build up to fully working systems. The Challenge page provides open-ended problems that you solve by designing the right infrastructure. It gives you the chance to put the lessons you learned into practice.
  • An AI assistant on the bottom, built with AWS Bedrock, provides you with assistance to your current task. From lessons to challenges, the AI assistant is there to offer hints, explain complicated concepts, or provide advanced reasoning.
