Project

Capacitive Proximity Gripper

A closed-loop robotic gripper that senses objects in the air and grasps them before contact, self-centering with two independently driven jaws. Research at the Columbia Laboratory for Unconventional Electronics.

View the presentation →

Overview

Robot perception leans on vision and touch, which leaves a blind spot in the moment a hand is closing on an object. This project adds capacitive proximity sensing to fill that gap: the gripper detects an approaching object before any contact and closes each jaw in proportion to how near the object is.

Each jaw carries an exposed copper antenna wired to a Cypress PSoC running two independent CSDv2 proximity channels. The firmware streams a per-jaw proximity signal over UART; a Python controller maps it to Dynamixel motor velocity, fast when the object is far and easing to a smooth stop near contact. Because each jaw follows only its own sensor, the gripper self-centers around objects placed off to one side, with no explicit position commands. The mechanism builds on the open-source LEGATO gripper.

Key Features

  • Two independent CSDv2 capacitive proximity widgets, one per jaw, each reading an exposed copper antenna at the jaw tip. Detection is the difference between the raw count and a locked baseline, rising as an object approaches, no contact required.
  • Per-jaw velocity follows a quadratic curve, vel = VEL_MAX × (1 − ratio)² + VEL_MIN, so the jaws move quickly while the object is far and decelerate smoothly as they close in.
  • On boot the firmware waits three seconds, samples 20 scans of true-idle data, then locks the baseline, so a hand near the sensor at power-on can’t corrupt the reference.
  • Software PWM dims the two LED proximity indicators inside the CapSense hardware busy-wait window, so no extra timer peripheral is needed. UART streams the proximity data in a compact P:<d1>,<d2> format at about 15 Hz for the Python layer.
  • A grip-and-release state machine (detect → hold 3 s → open → cooldown) uses a hold timer that ignores momentary sensor dropouts. A second controller keeps a target proximity on both jaws with proportional control, reopening and re-acquiring automatically when the object is lost.
  • IDAC saturation once pinned the raw count at the 12-bit ceiling and blinded the sensor. Root cause: the modulator current was set too low, overdriving the CSD integrator mid-scan. Fixed by restoring IDAC_MOD0 and the sensing clock and raising the conversion count (100 → 300) to recover SNR instead.
  • Custom 2-layer PSoC sensor board in KiCad (~40 × 30 mm): antenna traces routed as wide copper fills at the jaw tips with a ground keepout underneath, the 2.2 nF Cmod cap placed right at the pin, internal-LDO VCCD decoupled separately, and a 1.27 mm SWD header for the MiniProg4.
