Project

Capacitive Proximity Gripper

A closed-loop robotic gripper that senses objects in the air and grasps them before contact, self-centering with two independently driven jaws. Research at the Columbia Laboratory for Unconventional Electronics.

View the presentation →

Overview

Robotic perception leans on vision and touch, which leaves a blind spot in the moment a hand is closing on an object. This project adds capacitive proximity sensing to fill that gap: the gripper detects an approaching object before any contact and closes each jaw in proportion to how near the object is.

Each jaw carries an exposed copper antenna wired to a Cypress PSoC microcontroller running two independent capacitive proximity channels. The firmware streams a per-jaw proximity signal over UART; a Python controller maps it to Dynamixel motor velocity, fast when the object is far and easing to a smooth stop near contact. Because each jaw follows only its own sensor, the gripper self-centers around objects placed off to one side, with no explicit position commands. The mechanism builds on the open-source LEGATO gripper.

Abstract

Autonomous robotic hands often rely on cameras for long-range vision and on tactile sensors for physical contact. However, when a hand gets incredibly close to an object without touching the object, it blocks the camera view and creates a blind spot in robotic sensory data. This challenge is especially critical for projects like the dexterous robotic hand being developed by Columbia University’s CLUE and ROAM labs, which relies on advanced touch sensing without cameras. To bridge the gap between vision and touch, capacitive proximity sensors can be implemented to provide continuous pre-contact awareness for safe, reactive object engagement. This work presents the design and fabrication of a parallel gripper featuring capacitive proximity sensors to validate the necessity of these sensors in Columbia’s dexterous robotic hand.

The system uses an embedded Cypress microcontroller with built-in capacitive sensors to detect capacitive changes as a conductive object approaches. Fine tuning was applied for both metallic conductors, like metals, and ionic conductors, like human hands. Using a custom Python control script, the system translates these proximity measurements in real time to adjust the gripper’s motors. This enables the fingers to close rapidly from a distance and automatically slow down as they near the target, preventing harsh collisions and ensuring a soft grasp. To move beyond breadboard experiments, a PCB was designed to make the electronics compact and reliable. Continued experimentation hopes to provide a practical framework to enhance object manipulation and reactive control in robotic hands, specifically Columbia’s dexterous robotic hand.

Key Features

  • Each finger carries a capacitive proximity sensor: an exposed copper antenna that, together with the board’s ground plane, forms the two plates of a capacitor, C = κ · ε₀ · A / d (dielectric constant, permittivity of free space, plate area, plate spacing). A conductive object moving into the field between the antenna and ground acts like a plate in the middle, splitting the gap into two capacitors in series, so as the object gets closer the spacing d shrinks and the total capacitance C goes up. Nothing has to touch the finger.
  • The PSoC turns that capacitance into a 12-bit number from 0 to 4095: raw count = Cs · Vsupply · N / (Cmod · IDAC), where Cs is the sensor capacitance, Cmod a fixed 2.2 nF reference, N the 4096 conversion steps, and IDAC the drive current. Every term except Cs is fixed, so the raw count simply tracks the sensor capacitance. At startup the firmware records the idle value as a baseline and from then on watches raw minus baseline: that difference climbs as an object approaches, and once it passes a set threshold the object counts as detected, with its size standing in for distance and setting how fast the jaw closes.
  • Modified an open-source parallel-jaw gripper by CADding wire channels for the sensors, finger-shaped claws, and a base for the gripper. The base holds a power hub for the Dynamixel servos and a mount for the electronics.
  • The power hub distributes 12 V to the two Dynamixel servos, and a U2D2 converter establishes communication from the laptop to the servos. The proximity sensors on the microcontroller are programmed with a MiniProg4 and also connect to the laptop.
  • A single Python loop uses the Dynamixel SDK and pySerial to read the proximity data over UART from the PSoC and drive the motors at the same time.
  • Two control modes: a grip-and-release cycle (detect an object → close → hold 3 s → open → pause) and a follow mode that holds a set distance from a moving hand using proportional control.
  • Jaw speed follows a quadratic curve, quick while the object is far away and easing to a gentle stop as it gets close.
  • A custom PCB folds the breadboard wiring down onto one compact board.
